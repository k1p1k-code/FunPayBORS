# Использование плагинов
*Лоуд плагинов с python скрпита экспереминтальная*
___

# Через панель
1. Открыть панель 
2. Открыть раздел ```Plugins```
3. Нажать выбрать файл в .zip формате, который имеет сигнатуру плагина для FunPayBORS
4. Нажать Install Plugin, подождать
